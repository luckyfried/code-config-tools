# Font licenses

The film sets its type only in the faces its style card names, and each style's faces are in `styles/<style>/`
beside that family's license, `OFL.txt`. Every one is licensed under the SIL Open Font License 1.1, from the Google
Fonts repository (github.com/google/fonts, `ofl/`), and is free for commercial use. Local files only; nothing loads
from the network.

| Style | Faces |
|---|---|
| scrapbook | Caveat Brush, Gloock |
| analog-home-movie | Young Serif, VT323 |
| editorial-quiet | Instrument Serif (regular and italic), Hanken Grotesk |
| kinetic-type | Anton, Bricolage Grotesque |
| swiss-grid | Geist, Geist Mono |
| cinematic-letterbox | Cinzel, Cormorant |

Full OFL 1.1 text: https://openfontlicense.org/open-font-license-1-1/
